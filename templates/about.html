Multi-Agent Customer Support System

AI-powered customer support using Flask, LangGraph, Groq and SQLite.

Project Overview

This project is an AI-powered customer support platform that automatically understands customer queries, routes them to the correct specialist AI agent, stores conversations, and provides intelligent responses using Large Language Models.

Key Features

Intent Routing

Automatically routes queries to the correct AI agent.

AI Agents

Billing, Technical, Account and General Support.

Memory

Stores conversation history using SQLite.

Dashboard

View conversation statistics and analytics.

Technology Stack

Python

Flask

LangGraph

Groq

SQLite

CSV

System Workflow

User Query
↓
Triage Agent
↓
Billing / Technical / Account / General Agent
↓
Escalation Agent (If Required)
↓
Final Response
